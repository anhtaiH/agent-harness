# Task Packet

Use this when starting non-trivial work.

- State the goal, repo, worktree, risk, scope, verification, and stop conditions.
- Keep the packet source-backed.
- For yellow/red or high/critical risk, require a sprint contract before edits.
- Do not store sensitive raw material in task artifacts.
