# Evidence Gate

Before claiming completion:

1. Record positive proof.
2. Record negative proof or failure-mode checks.
3. List commands run.
4. Explain skipped checks and residual risk.
5. Note diff risk and mitigation.
6. Add only source-backed memory candidates.
7. Run the evidence doctor.
